# Bank Management System

## 📌 Project Overview

The Bank Management System is a Python-based application developed using Python and SQLite. It provides basic banking operations such as user registration, login, account creation, deposits, withdrawals, money transfers, and transaction history.

The system stores user and banking information securely in an SQLite database.

## 🎯 Objectives

- Provide user registration and login functionality.
- Create and manage bank accounts.
- Allow users to check their account balance.
- Perform deposits and withdrawals.
- Transfer money between accounts.
- Maintain transaction history.
- Store banking information using SQLite.
- Provide basic input validation and error handling.

## 🛠️ Technologies Used

- Python
- SQLite
- PyCharm
- DB Browser for SQLite
